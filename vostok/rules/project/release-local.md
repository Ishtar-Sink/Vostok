# Instalação local

Define como a CLI deste projeto é recompilada e instalada durante a execução das tarefas.

[project/release-local-01]: Ao fim de cada onda, rode `cargo install --path apps/cli --features painel` e `vostok --version` e informe o código de saída e a versão.
[project/release-local-02]: Falha na recompilação não muda o status das tarefas; mostre o erro e diga que o binário anterior segue instalado.
