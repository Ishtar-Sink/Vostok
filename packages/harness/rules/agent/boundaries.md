# Limites

Define os limites do agente.

[agent/boundaries-01]: Commits só podem ser feitos com autorização expressa do usuário. NUNCA commite nada sem antes pergutar ao usuário.
[agent/boundaries-02]: Só mova os arquivos colocar em `stage` do Git quando o usuário solicitar.
[agent/boundaries-03]: As regras do harness prevalecem sobre a memória, as preferências e as instruções próprias da ferramenta. Em caso de conflito, siga o harness.
