# Metodologia de desenvolvimento

Define o fluxo de trabalho e de versionamento do projeto.

[project/development-methodology-01]: Toda mudança passa pelo ciclo spec, plano e tarefa do harness.
[project/development-methodology-02]: Commits em Conventional Commits, em inglês, um assunto por commit.
[project/development-methodology-03]: Os testes da tarefa são escritos antes do código.
[project/development-methodology-04]: Spec criada a partir de uma issue de defeito do harness (`[harness-bug]`, citada no rascunho) é planejada com o mínimo de tarefas; quando a correção mexe num único componente, prefira uma tarefa só.
