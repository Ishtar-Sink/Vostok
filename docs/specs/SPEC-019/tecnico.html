Visão geral

A CLI ganhou vostok task brief, que monta o roteiro de uma tarefa in_progress com baseline (regras de limites e segurança, persona, roteiro e a seção "Execução"), e vostok task check, que roda a "Verificação" sem mexer no status e imprime só o resumo. config/tasks.yml ganhou max_subagents. As definições de agente do Claude Code ganharam maxTurns e passaram a mandar rodar o brief. As skills execute-task, approve-plan e finalize-spec mudaram para o Coordenador executar por padrão, citar trechos em "Ler" e finalizar sem subagente.

23## Como o custo cresce
24
25- Cada chamada ao modelo reenvia o contexto inteiro da conversa. Com o prompt caching, a parte repetida é lida do cache a uma fração do preço, mas continua contando no uso do plano.
26 - O custo de um agente é aproximadamente o tamanho do contexto multiplicado pelo número de turnos (cada chamada de ferramenta é um turno), somado à saída e ao raciocínio.
27- Cada subagente abre um contexto novo. Ele grava no cache tudo o que carrega no início e paga de novo a leitura a cada turno. Subagentes não reduzem o trabalho: só tiram o volume do contexto do chat principal.
28 - A documentação oficial diz isso explicitamente: as requisições do subagente contam no mesmo limite de uso.

32 - A mesma tarefa num subagente com 50 mil tokens de contexto relê cerca de 650 mil.
