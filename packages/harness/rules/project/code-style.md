# Estilo de código

Define como o código deve ser escrito para ser legível por pessoas.

[project/code-style-01]: Clean code em todas as camadas: nomes que dizem o que a coisa é e funções pequenas com uma responsabilidade.
[project/code-style-02]: O código deve ser legível sem comentários. Comentário só explica o porquê, nunca o que o código já diz.
[project/code-style-03]: Sem código morto nem código comentado.
[project/code-style-04]: Formatação e lint automáticos: `rustfmt` e `clippy` no Rust; ESLint e Prettier no TypeScript.
