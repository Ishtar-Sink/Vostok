# Documentos de apoio do estudo do painel local

Apoio do [estudo do painel local](../painel-local.md), da SPEC-027.

O código do protótipo não entra na `main`. Ele fica só no branch `spike/painel-local`, na worktree `/home/victor/projetos/ai-hub-painel`, sem commit. As imagens abaixo são a única parte do protótipo que entra no repositório.

## Documentos

- [levantamento.md](levantamento.md) (TASK-01): o inventário das ações do chat e a forma de cada uma no painel, as alternativas de aprovação pelo painel e as mudanças para remover a premissa de servidor (PQ-05, PQ-06, PQ-11).
- [medicoes.md](medicoes.md) (TASK-02): o tamanho do binário e do bundle com `tiny_http` e `axum`, React e Preact, o impacto de Node no build e o primeiro limite proposto (PQ-02, PQ-03, PQ-04).
- [prototipo.md](prototipo.md) (TASK-03): como reproduzir o protótipo, as telas, a marca e os componentes do Atria, a atualização ao vivo, o tamanho completo, os painéis ao mesmo tempo e o retorno do usuário (PQ-01, PQ-09, PQ-10, PQ-12).
- [testes.md](testes.md) (TASK-04): os testes da aprovação, da edição, da edição simultânea e do pedido processado por um chat em `/loop`, e o desenho para o Codex (PQ-01, PQ-06, PQ-07, PQ-08).
