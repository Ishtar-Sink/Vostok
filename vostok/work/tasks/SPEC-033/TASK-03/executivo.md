Os avais que você dá pelo painel passam a ficar num arquivo por spec, em vez de um arquivo único que só cresce. Um comando novo mostra os avais de uma spec ou tarefa, do mais novo para o mais antigo, para que o agente nunca precise abrir esses arquivos.

Na primeira execução da versão nova, o arquivo antigo é dividido por spec, uma vez, sem alterar nenhuma linha. Perfil julgamento, risco alto: a trava de aval depende desses arquivos para aceitar ou recusar uma conclusão. Desbloqueia o arquivamento dos avais com a spec (TASK-05) e as ações novas do painel (TASK-08).
