Migração do Harness para Rust

O Vostok deixou de ser um conjunto de scripts que só funcionava dentro deste repositório e virou um programa único, instalável em qualquer projeto, que já traz consigo as skills, as regras e os modelos do método. A versão 0.1.0 foi publicada para Linux e macOS, com instalação em um passo, e reproduz o comportamento dos scripts antigos, conferido contra 639 casos gravados. O próprio projeto passou a usar o programa, sem perda de histórico, e os testes ficaram cerca de 30% mais rápidos.

As 4 entregas

Abra cada entrega para ver o que mudou, o valor e como perceber.

Programa único com o método embutidoImpacto alto

O que mudoutodas as operações do método (contexto, memória, regras, especificações, planos, tarefas, commits, skills e finalização) passaram a ser feitas por um único programa, que carrega dentro de si o conteúdo do método.

Valoro método deixa de depender deste repositório e pode ser adotado por qualquer projeto, com o mesmo comportamento de antes e uma base mais fácil de manter que milhares de linhas de scripts.

Como percebero mesmo fluxo de trabalho das skills continua funcionando, agora chamando o programa novo.

Instalação e atualização em qualquer projetoImpacto alto

O que mudouum projeto novo recebe o método com uma inicialização guiada, que pergunta onde ficam os documentos e quais ferramentas de IA a equipe usa (Claude Code, Codex, Cursor), e só elas recebem a configuração. Uma atualização posterior traz as novidades da versão sem apagar o que é do projeto e guarda uma cópia de qualquer arquivo que a equipe tenha personalizado.

Valoradotar o método passa a ser uma instalação seguida de uma inicialização guiada, e atualizá-lo não põe em risco o trabalho nem as personalizações do time.

Como perceberdepois da inicialização, o projeto tem a pasta do método e as instruções para as ferramentas escolhidas, e nada para as que não foram escolhidas.

Versão 0.1.0 publicadaImpacto alto

O que mudoua primeira versão foi publicada no GitHub da organização, com o programa pronto para as quatro combinações de Linux e macOS, e um instalador detecta o sistema e baixa a versão certa.

Valorqualquer pessoa instala o Vostok com uma linha, sem precisar compilar nada; o instalador foi usado com sucesso no Linux e num Mac com Apple Silicon.

Como percebera página da versão no GitHub lista os quatro pacotes, e o programa instalado informa a versão 0.1.0.

Este projeto migrado e os scripts aposentadosImpacto médio

O que mudouo próprio repositório do Vostok passou a usar o programa instalado, como qualquer outro projeto, e os scripts antigos e sua bateria de testes foram removidos.

Valora equipe usa no dia a dia exatamente o que entrega, o que expõe defeitos cedo; todo o histórico de especificações, tarefas e memória foi preservado e conferido.

Como perceberas especificações e tarefas existentes continuam listadas e acessíveis, e não há mais scripts no método.

Riscos e limitações
  • Não há versão para Windows.
  • A equivalência com os scripts foi conferida contra casos gravados; situações fora desses casos só aparecem com o uso real.
  • O programa foi exercitado de ponta a ponta apenas neste projeto e nos cenários de teste; ainda não há adoção em projetos externos.
  • Pequenos acabamentos apontados nos cenários de teste (textos e formatação de algumas mensagens) ficaram para versões seguintes.
