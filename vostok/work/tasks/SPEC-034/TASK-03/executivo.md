Quando uma spec aprovada é ajustada, a aprovação cai e a spec volta para revisão, mas o histórico de status não registrava essa volta e parecia que ela tinha sido aprovada duas vezes seguidas. Esta tarefa passa a registrar a volta no histórico, para que o caminho de cada spec fique fiel ao que aconteceu. Também corrige a mensagem que avisa de uma aprovação pelo painel sem registro, que ainda apontava para o arquivo antigo dos avais em vez do arquivo da spec.

Perfil padrão, risco baixo: correção pequena e isolada, sem dependências, na primeira onda. Não bloqueia outras tarefas.
