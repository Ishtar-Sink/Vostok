# Conectores do projeto

Lista os projetos em cada conector utilizado pelo projeto. Os valores estão em variáveis de ambiente (`.env.example` lista as variáveis, sem valores).

| Conector | Variável |
|---|---|
| Figma | `FIGMA_PROJECT_URL` |
| Draw.io | `DRAW_IO_DIAGRAM_URL` |
| Google Drive | `GOOGLE_DRIVE_FOLDER_URL` |
