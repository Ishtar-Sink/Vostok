# Glossário

Termos próprios do harness. Ao escrever para pessoas, use a palavra comum ou explique o termo na primeira menção ([agent/writing-05]).

| Termo | O que significa |
|---|---|
| Spec | A especificação: o documento que diz o que será feito e como saber que ficou pronto. |
| Rascunho | A spec ainda sem refinamento, só com o que o usuário disse. |
| Refinada | A spec depois das perguntas e da investigação, com requisitos e testes. |
| Plano | A divisão da spec aprovada em tarefas, antes de as tarefas serem criadas. |
| Tarefa | Uma parte pequena da spec, executada e conferida separadamente. |
| Onda | Um grupo de tarefas que podem andar ao mesmo tempo. |
| Perfil de execução | O quanto a tarefa exige de quem a executa: mecânica, padrão ou julgamento. |
| Baseline | A saída de comandos medida antes da mudança, para comparar depois e achar o que quebrou. |
| Regressão | Algo que funcionava antes da mudança e deixou de funcionar. |
| Evidência | A prova de que a tarefa entregou o combinado: um log, um print ou um vídeo. |
| Evidência antecipada | A evidência gerada logo depois da execução, antes de a tarefa ser finalizada. |
| Conferência | A decisão do usuário de aceitar ou recusar uma evidência. |
| Aval | A autorização do usuário para uma ação, como finalizar uma tarefa ou fazer um commit. |
| Coordenador | O agente que conduz a conversa e dispara os demais. |
| Critério de aceite | Uma condição da spec que precisa ser verdadeira para ela ser considerada pronta. |
| ID | O código de um item da spec (RF, CT, CB, RN, CA), usado para rastrear a cobertura. |
| Finalização | O fechamento da spec: gera os documentos finais e a arquiva. |
