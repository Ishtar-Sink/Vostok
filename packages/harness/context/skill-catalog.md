# Catálogo de Habilidades

## Padrão

Habilidades incluídas junto ao harness.

| Habilidade | Descrição | Caminho |
|    ---     |    ---    |   ---   |
| refine-spec | Refina uma especificação (spec) em rascunho. Investiga o projeto e a memória, identifica ambiguidades, conflitos e lacunas, resolve com o usuário em rodadas de perguntas e gera em `refined/` uma spec detalhada, com seções conforme o tipo (feature, improvement, fix, study, analysis). Use quando o usuário pedir para refinar, detalhar ou esclarecer uma spec em rascunho (status draft), ou perguntar quais specs em draft estão prontas para refinamento. Não use para specs já refinadas: ajustes nelas são feitos pela skill adjust-spec. | `../skills/default/refine-spec` |
| create-skill | Cria uma nova skill do harness no formato padrão: gera o SKILL.md a partir do template, os scripts da skill, os redirecionamentos para Claude Code, Codex e Cursor e a entrada no catálogo. Use quando o usuário pedir para criar, adicionar ou gerar uma skill ou habilidade, ou transformar um fluxo de trabalho em skill. Use sempre esta skill em vez dos criadores de skill nativos das ferramentas. | `../skills/default/create-skill` |
| adjust-spec | Ajusta uma especificação (spec) já refinada, com status refined ou approved. Aplica um ou vários ajustes pedidos numa mesma mensagem, em prosa, em lista ou citando o trecho exato, registra edições feitas à mão e mantém o histórico de ajustes da spec, validando-a com as mesmas regras do refinamento. Use quando o usuário pedir para ajustar, corrigir, mudar, alterar, acrescentar ou remover algo de uma spec refinada ou aprovada, ou comentar a spec logo depois de ela ser refinada ou ajustada. | `../skills/default/adjust-spec` |
| approve-spec | Aprova uma especificação (spec) refinada, com status refined. Confere se a spec está válida, sem pendências abertas e sem edições manuais sem registro, muda o status para approved, grava a versão aprovada para a granularização e remove o rascunho. Use quando o usuário pedir para aprovar uma spec, disser que aprova ou que a spec está aprovada, ou citar um ID como SPEC-001 para aprovação. | `../skills/default/approve-spec` |
| plan-tasks | Planeja as tarefas de uma especificação (spec) aprovada, com status approved. Cria um plano para revisão em work/plans/, com a visão geral, a tabela de tarefas, as dependências, os IDs cobertos e o nível de esforço sugerido de cada tarefa, calculado por script. Use quando o usuário pedir para planejar, propor, granularizar ou quebrar em tarefas uma spec aprovada. Não use para ajustar um plano existente (skill adjust-plan) nem para aprová-lo (skill approve-plan). | `../skills/default/plan-tasks` |
| adjust-plan | Ajusta o plano de tarefas de uma especificação (spec) aprovada, em work/plans/. Aplica um ou vários ajustes pedidos numa mesma mensagem (dividir, juntar, remover ou reordenar tarefas, mudar dependências, cobertura ou fatos de esforço), registra edições feitas à mão, recalcula os níveis e mantém o histórico de ajustes do plano. Use quando o usuário pedir para ajustar, corrigir, mudar, dividir, juntar ou remover algo do plano de tarefas, ou comentar o plano logo depois de ele ser criado ou ajustado. | `../skills/default/adjust-plan` |
| approve-plan | Aprova o plano de tarefas de uma especificação (spec) aprovada. Cria um arquivo por tarefa na pasta de tarefas da spec, em work/tasks/, detalha cada uma com a execução para o agente (arquivos, passos, verificação) e a descrição para pessoas (resumo executivo, detalhes técnicos e card para board), remove o plano e marca a spec como planned. Use quando o usuário pedir para aprovar o plano de tarefas ou disser que aprova o plano. | `../skills/default/approve-plan` |
| approve-commit | Faz commits a pedido do usuário, já liberados, e libera ou desfaz os commits apontados pela verificação de commits (check-commits.sh): commits feitos sem liberação, pelo agente ou pelo próprio usuário. Liberar grava o estado atual do repositório como referência; desfazer remove os commits novos da branch atual mantendo as alterações na pasta de trabalho. Use quando o usuário pedir para fazer commit, ou para liberar, aprovar, aceitar, desfazer ou reverter os commits apontados. | `../skills/default/approve-commit` |
| approve-task | Aprova tarefas de uma especificação (spec) planejada, em work/tasks/: uma, várias ou todas as pendentes. Confere se cada tarefa está pendente, sem edição manual sem registro e válida, e grava a aprovação em todas ou em nenhuma. Use quando o usuário pedir para aprovar tarefas, citar IDs como TASK-01 para aprovação ou disser que aprova as tarefas. | `../skills/default/approve-task` |
| adjust-task | Ajusta uma tarefa de uma especificação (spec) planejada, em work/tasks/, com status pending ou approved. Aplica um ou vários ajustes pedidos numa mesma mensagem (arquivos a ler ou mudar, passos, baseline, verificação, evidências, critérios de conclusão ou descrição), registra edições feitas à mão e mantém o histórico de ajustes da tarefa. Uma tarefa aprovada volta para aprovação. Use quando o usuário pedir para ajustar, corrigir, mudar ou detalhar algo de uma tarefa, ou comentar uma tarefa antes de executá-la. | `../skills/default/adjust-task` |
